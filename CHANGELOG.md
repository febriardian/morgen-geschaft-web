# Changelog

Perubahan penting pada Morgen Geschäft dicatat dalam file ini.

Format mengikuti kelompok Added, Changed, Fixed, Security, dan Removed. Versi
project menggunakan Semantic Versioning.

## [1.0.0] - 2026-08-29

### Added

- Storefront bilingual Indonesia dan English.
- Panel administrasi untuk produk, pesanan, promo, konten, ulasan, dan retur.
- Checkout Midtrans dan integrasi pengiriman Biteship.
- Akun pelanggan berbasis OTP email, loyalty points, dan referral.
- Chatbot GESA, notifikasi, kuis tipe kulit, dan distribusi APK dari website.
- Dokumentasi project, kebijakan keamanan, template kontribusi, dan MIT License.

### Security

- Quality gate untuk lint, test, build, dependency audit, dan pemeriksaan file
  sensitif.
- Validasi transaksi, webhook, role admin, upload, rate limit, dan Firestore
  rules.
